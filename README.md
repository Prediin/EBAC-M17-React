# Módulo 17 — React

Primeiros projetos em React com Vite: prática de componentes, hooks e contexto, além de um catálogo de produtos.

**Tecnologias:** React, React DOM, Vite, JavaScript/JSX, TypeScript, Sass/SCSS e styled-components.  
**Conteúdos:** componentes, props, estado, hooks, Context API, formulários, listagem de tarefas e composição de interfaces.

## Projetos

- `pratica1-Vite`: tarefas, login, hook personalizado e contexto de usuário.
- `pratica2-Hooks`: exemplos de componentes e hooks em React.
- `exercicio1-Catalogo_de_Produtos`: catálogo baseado em dados JSON e componentes reutilizáveis.

Cada aplicação Vite pode ser executada a partir de sua respectiva pasta com `npm install` e `npm run dev`.
